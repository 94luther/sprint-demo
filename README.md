# Sprint, the phone

The Sprint Couriers delivery app on one phone screen.

**Example data only. This is not the live Sprint system.**

Add an item on the Shop tab, then open the Counter tab. The shop is reading the same
basket the customer filled, line by line. That is the whole design.

The department tiles describe what each internal screen does. Those screens are not
part of this demo and are not published here.

Shop names, addresses and prices are invented and are not a claim that Sprint Couriers
has an agreement with anyone. Photographs from Unsplash. Category icons by Icons8.

Open it: https://94luther.github.io/sprint-demo/
